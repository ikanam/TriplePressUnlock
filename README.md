# TriplePress Unlock（三击解锁）

面向 Android 掌机的防误触工具：按电源键亮屏后，连续按三次同一个支持的手柄按键或单指滑动屏幕，即可解除全屏覆盖层；3 秒没有有效输入则自动息屏。

这不是密码锁。它只用于防止掌机放在包里时被触摸或手柄按键误操作，不能保护设备数据。

## 安装

调试 APK 位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```

通过 ADB 安装：

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Android 13 及以上版本可能限制侧载应用启用无障碍权限。如果服务开关不可用，请打开应用信息，点击右上角菜单，选择“允许受限设置”，然后再进入无障碍设置。

## 首次启用

1. 打开应用，将系统锁屏方式设为“无”。
2. 点击“打开无障碍设置”，启用“三击解锁服务”。
3. 返回应用，点击“立即测试锁定界面”。
4. 连续按三次同一个支持的按键，确认能够解除锁定。
5. 在设备的电池或后台管理中允许该应用自动运行，不要对它进行后台冻结。

## 触屏解锁

如果手柄不可用，可在锁定界面单指向任意方向滑动。触摸开始时会暂缓 3 秒自动息屏计时；未达到解锁距离时，松手后重新开始计时。

如果覆盖层或按键监听在特定掌机固件上不工作，请先禁用无障碍服务恢复正常操作。之后可通过：

```sh
adb shell settings put secure enabled_accessibility_services null
```

清空所有已启用的无障碍服务。这个命令会影响设备上的其他无障碍应用，只应作为开发调试时的最后手段。

## 构建

要求 JDK 17 或更高版本，以及包含 Android 36 SDK 的 Android Studio/SDK：

```sh
./gradlew assembleDebug
./gradlew lintDebug
```

项目只使用 Android 系统 API，没有第三方运行时依赖。
应用源码与单元测试均使用 Kotlin；界面提供简体中文和英文，并跟随 Android 系统语言自动切换。

## 常见问题

### 会明显增加耗电吗？

不会明显增加。应用采用事件驱动方式，只在屏幕亮灭、手柄按键或锁屏界面触摸等事件发生时处理少量逻辑；平时不会持续轮询、不联网，也不持有唤醒锁，因此后台耗电通常很小。实际耗电仍可能因掌机系统和固件的后台管理策略而有所不同。

### 服务被系统杀掉怎么办？

请检查掌机是否内置了限制 App 在后台运行的软件或系统功能，并将“三击解锁”加入后台运行、自启动或电池优化白名单。

### AYANEO 系统还需要额外设置吗？

需要。进入“设置 → 快霸”，打开“三击解锁服务”开关。
